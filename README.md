# The World's Most Breathtaking Landscapes 🌍

Welcome to **Landscapes Blog**! This is a static webpage built to showcase some of the most stunning natural wonders across the globe, from South Africa's Blyde River Canyon to Japan's Mount Fuji. 

This project was created as a hands-on practice exercise to strengthen foundational web development skills using pure HTML and CSS.

## 🚀 Live Demo
Check out the live website here: [Landscapes Blog on Netlify](https://landscapes-blog.netlify.app/)

## ✨ Features
* **Semantic HTML5:** Code structured for clean readability and accessibility.
* **Custom CSS3:** Styled entirely from scratch without the use of external CSS frameworks.
* **SEO & Social Sharing Ready:** Includes Meta and Open Graph (OG) so the site looks great when shared on social media platforms.
* **Responsive Viewport:** Configured to scale and render properly across different devices.

## 🛠️ Technologies Used
* **HTML5**
* **CSS3**
